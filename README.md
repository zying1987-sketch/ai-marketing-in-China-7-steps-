## 部署方式

### 方式一：GitHub Pages（推荐）

1. 进入仓库 `Settings` → `Pages`
2. Source 选择 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`
3. 保存后即可获得 `https://zying1987-sketch.github.io/ai-marketing-in-China-7-steps-/` 链接
4. 如需自定义域名，在 `Custom domain` 中填入并配置 DNS

### 方式二：直接发给客户

将 `index.html` 文件直接发给客户，双击即可在浏览器中打开查看。
